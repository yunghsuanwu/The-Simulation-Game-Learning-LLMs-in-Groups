# Contributing

## Proposing a new motivation set

Motivation sets live in [motivation_set.md](motivation_set.md), grouped into themed sets (Concentrated Order; Spatial Balance & Flow; Light & Visibility; Cognitive/Behavioural Environment). To propose a new set or new goals within an existing set:

1. Open a pull request adding your goals to `motivation_set.md`, following the existing format (an AI persona name, a one-sentence role description, and a concrete spatial goal).
2. In the PR description, say which existing sets your goals could conflict or align with — that relationship is what the game runs on, so it needs to be intentional, not accidental.
3. If you're proposing a new theme (a fifth set), explain briefly why it needs its own group rather than fitting into an existing one.

## Reporting a run

If you've run the workshop, please [open a run report issue](../../issues/new?template=run-report.md) using the template. This is how the repo builds up real provenance data (see [RUNS.md](RUNS.md)) instead of relying on word of mouth.
